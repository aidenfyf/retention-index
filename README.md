# The Retention Economy Index

> 50 niches where agencies become growth partners, not vendors — ranked by
> structural stickiness, contextualized with demand signal and operator tier.
>
> A research index by **8INMEDIA**. Live: https://research.8inmedia.com

## The thesis
The constraint is retention. Agencies that stall between **$8k–$30k/month** don't
stall because they can't find new clients — the clients they land churn out before
the agency ever compounds. This index ranks 50 agency niches by how *sticky* they
are, not how *in-demand* they are.

## How niches are scored
A composite **stickiness score** from four metrics:
- **Retention Gravity** — how structurally hard it is for a client to leave
- **Expansion Ceiling** — headroom to grow account value over time
- **Margin Architecture** — whether the economics support healthy margins
- **Operator Fit** — how well the niche suits the operator running it

Organized by **operator tier**: Institutional (S) · Specialty (A) · Founder-operator (B).
